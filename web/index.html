    CALIBRATION STARS / SEPARATE FROM VALIDATION AND TEST

    Calibrate on a natural cohort.

    The ensemble averages three dual-view scores. Its monotonic sigmoid is fitted only on calibration stars. The plot shows calibrated scores versus held-out catalog candidate frequencies. This selected KOI cohort does not represent all Kepler stars.

    BLIND DETECTION / REAL OBSERVATION BACKGROUNDS

    Can we recover injected transits?

    A strict recovery needs a period within 1%, epoch within one injected duration, and depth SNR ≥7.1. Half/double-period matches are recorded separately. Box injections omit limb darkening; this small experiment does not measure mission-wide completeness or CNN vetting accuracy.

    Study boundaries

    Every pilot star is excluded. The 4,000-star request uses no class balancing; stars must have usable quarters 9 and 10. Train/validation/calibration/test membership is fixed by a stellar-ID hash. Model selection uses validation only; calibration fits use calibration only. The original pilot remains available in the explorer.

    FROM PHOTONS TO A SCORE

    A pipeline you can defend.

    01 / ACQUIRE

    Start with real light.

    Frozen DR25 KOI dispositions and Q9 PDCSAP light curves from NASA’s Kepler archive. Only clean-quality cadences are retained. Every FITS file has a recorded SHA-256 checksum.

    02 / PREPARE

    Keep the dip intact.

    Mask the known transit while estimating the stellar trend. Fold by catalog period and epoch. Build a 512-bin full-orbit view and a 128-bin transit view, each with a missing-data mask.

    03 / LEARN

    Two views. One decision.

    Separate 1D convolutional branches learn local transit shape and wider orbital context. Their representations feed a shared classifier. Only training examples update the weights.

    04 / CHALLENGE

    Test on unseen stars.

    Split by Kepler star ID. Select the checkpoint and decision threshold on validation. Compare held-out performance with a simple baseline and bootstrap uncertainty.

    Advanced project roadmap

    This is a working pilot, not a reproduction of the full AstroNet experiment. The Research Study tab includes Q9/Q10 data, three-seed input ablations, separate calibration, and a blind BLS injection/recovery experiment. Further work should expand period coverage, injection physics, and independent population validation.
